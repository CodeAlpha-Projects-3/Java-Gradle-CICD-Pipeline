# 🚀 Java Gradle CI/CD Pipeline

A simple DevOps project demonstrating **CI/CD automation** for a Java application using **Gradle** and **Jenkins**.

---

## 📌 Overview

This project automates the Java application build process using Jenkins pipelines and Gradle build automation.

It demonstrates:

- ✅ Java build automation
- ✅ Gradle dependency management
- ✅ Jenkins CI pipeline
- ✅ Automated build workflow
- ✅ Pipeline as Code using Jenkinsfile

---

- ☕ Java
- 🐘 Gradle

- 🐙 Git & GitHub
- 🐧 Linux

## 🚀 Build Command

### Linux / Mac

```bash
./gradlew build
```

### Windows

```bash
gradlew.bat build
```
